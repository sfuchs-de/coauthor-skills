# Public packaging audit

Prepared on October 7, 2026 from the installed skill packages, not from manuscript repositories or
credential stores. Each original resource has a source hash and a disposition in
`packaging-provenance.json`. `MANIFEST.json` records the distributed file hashes.

  byte-for-byte. No confidential reports, archive cases, manuscripts or evaluation outputs are
  copied from the private reviewing archive.

## Verification boundaries

Offline validation scans UTF-8 resources and SQLite text, checks integrity and local Markdown
links, parses Python, and rejects source/binary documents and credential-shaped values. This is
not a guarantee against every possible secret or a legal determination of third-party rights.
The explicit allowlist and private-source exclusions are important alongside scanning.

Portable corpus verification checks all five inventories and checker behavior without acquiring
the source papers. These tests do not independently re-review the economics or prove that the
skills reliably produce correct first-pass writing. External citations, current provider policies
and project-specific scientific claims still require their own checks.

The repository has no automatic GitHub Actions workflow. Run the documented checks locally;
publication is one coherent initial push after acceptance, keeping remote CI usage minimal.

Git attributes preserve original bytes across platforms. Whitespace checks accept inherited
CRLF records and final blank lines, while still checking trailing spaces and tabs. Frozen corpus
resources and the referee-report package are not reformatted merely to satisfy Git defaults.
