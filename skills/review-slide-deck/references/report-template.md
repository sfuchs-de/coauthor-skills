# Review report template

Scale this template to the review mode. Omit empty sections rather than filling them with generic advice.

## Overall diagnosis

In one paragraph, state whether the deck can deliver its central argument to the intended audience in the available time, and identify the main constraint.

**The talk in one sentence:** [question → answer → evidence → implication]

## Highest-value changes

List three to five changes in priority order. For each, give the affected slides, audience consequence, and concrete remedy.

## Rehearsal notes

Separate delivery changes from deck changes. Include the opening sentence, difficult transitions, planned pauses, slides likely to attract interruptions, and the closing sentence only when useful or requested.

## Verification note

State what was inspected: source format, slide count, rendered pages, compilation status if applicable, and any missing source, notes, animation, or audience information that limits the review.
