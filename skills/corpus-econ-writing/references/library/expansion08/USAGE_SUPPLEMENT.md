# Theory Usage Distinctions

These distinctions guide meaning; they do not exempt a form from attestation.
The newly found `euro` occurrence is the bibliography abbreviation `Euro. Econ.
Rev.` in TH02 p14, not the currency. It remains searchable but does not license
currency prose. The checker reports this contextual restriction explicitly.

| Distinction | Use In An Argument | Source Anchor |
|---|---|---|
| Envelope formula / regularity | State the derivative and the conditions supporting its use separately. | TH01 pp4-5 |
| Fixed choice set / parameterized constraint | A change in feasibility can contribute through constraint multipliers. | TH01 pp16-17 |
| Differentiability / absolute continuity | A derivative at a point and an integral representation have different premises. | TH01 p5 |
| Expenditure / budget share | Define the cost of utility before its log-price derivative. | TH02 p2 |
| Demand representation / empirical acceptance | A theoretically restricted system can have rejected implications. | TH02 pp1,12 |
| Partial / total derivative | Name held-fixed arguments and count policy feedback once. | TH03 pp11,28 |
| Revenue / welfare | Specify who pays and how revenue returns; a payment is not automatically a loss to all residents. | TH03 pp10-11 |
| Expenditure channel / earnings channel | Different baskets do not alone specify income incidence. | TH04 p4 |
| Individual / aggregate demand | State restrictions permitting the transformation. | TH04 pp9,13 |
| Predetermined / flexible input | Timing describes which input can respond in the relevant problem. | TH05 pp6-7 |
| Mean log shock / expectation of its exponential | Centering a log shock does not set the level correction to one. | TH05 pp7,18 |
| Optimization / identification | A first-order condition supports a regression only with its additional restrictions. | TH05 p17 |
| Competitive / efficient allocation | Define feasibility and private optimization before welfare comparisons. | TH06 p13 |
| General / specialized model | Keep the scope of a result attached to the assumptions producing it. | TH06 pp10,20 |

Hyphenated labels such as "fixed-transfer" can be convenient drafting notes, but
attested "fixed" and "transfer" do not by themselves attest that compound. Prefer
a grammatical phrase such as "with the transfer fixed" when it preserves the
meaning. "Nonsingularity" concerns an inverse; convergence of successive rounds
needs a separate condition. These are distinctions to preserve, not stylistic
reasons to add a new technical concept.
