# Expanded Source Study

Eight additional papers; selected passages on 68 PDF pages. The full 502-page extraction is not a claim of full manual reading.

The maps and observations are original editorial analyses. They do not certify proofs, estimates, or an individual coauthor's writing process. Versions are pinned by acquisition hashes, not inferred from a website's current publication status.

## D07

[The Textbook Case for Industrial Policy: Theory Meets Data](https://dave-donaldson.com/wp-content/uploads/BCDR.pdf)

Dominick Bartelme; Arnaud Costinot; Dave Donaldson; Andres Rodriguez-Clare. Published JPE article, May 2025.

Selected passages: PDF pp2, 3, 4, 5, 8, 9, 10, 14, 35, 42.

**Argument map:** Policy question -> externality -> optimizing agents -> welfare characterization -> elasticity estimation -> policy comparison -> sensitivity.

- PDF p2, structure: The opening carries one policy question into theory, estimation, and quantification.
- PDF p8, sequence: General utility and technology are defined before policy-specific restrictions.
- PDF p9, math: Firm and household objectives precede the equilibrium conditions.
- PDF p10, scope: The government objective and which foreign variables are taken as given accompany the policy result.
- PDF p14, handoff: The theory identifies which elasticities the empirical exercise must recover.
- PDF p35, interpretation: Sensitivity is explained through the parameter's two roles rather than a list of alternative columns.

## D08

[Persistence and Path Dependence in the Spatial Economy](https://dave-donaldson.com/wp-content/uploads/Path_Dependence.pdf)

Treb Allen; Dave Donaldson. Author manuscript dated October 2022, not asserted to be latest published version.

Selected passages: PDF pp1, 2, 3, 4, 7, 12, 13, 14, 26, 41.

**Argument map:** Historical concentration -> persistence question -> forward-looking choices -> dynamic equilibrium -> recovery -> historical counterfactual.

- PDF p2, question: A spatial pattern becomes separate questions about location and aggregate efficiency.
- PDF p3, quantifiers: Unique dynamics, slow convergence, and multiple steady states are distinguished.
- PDF p7, timing: The life sequence motivates which decisions depend on future values.
- PDF p12, exposition: The value function is explained through current consumption and descendants' choices.
- PDF p26, data: A recovery step declares missing years and the historical records used instead.
- PDF p41, conclusion: The ending reconnects mathematical distinctions to what temporary history can change.

Selected passages: PDF pp1, 2, 5, 6, 7, 8, 9, 16.

**Argument map:** Computational question -> interaction system -> elasticity bounds -> theorem -> economic application -> comparison.

- PDF p2, object: The interaction system is motivated by computation and uniqueness questions.
- PDF p5, literature: Earlier mathematical approaches are compared by restrictions and dimensionality.
- PDF p6, definitions: Indices, positive domain, and elasticities are defined before the theorem.
- PDF p7, quantifiers: A sufficient condition and a construction outside that condition have different quantifiers.
- PDF p9, interpretation: The iteration receives a best-response interpretation under the specified system.
- PDF p16, scope: The application distinguishes general spillovers from a more restrictive functional form.

## K05

[General Equilibrium Effects in Space: Theory and Measurement](https://arkolakis.com/wp-content/uploads/AAE.pdf)

Rodrigo Adao; Costas Arkolakis; Federico Esposito. Author manuscript dated September 2025.

Selected passages: PDF pp1, 2, 3, 4, 5, 10, 15, 16, 17, 40.

**Argument map:** Missing aggregate effect -> linked exposure evidence -> model disagreement -> response representation -> estimation -> incidence.

- PDF p2, argument: Differential evidence and aggregate recovery are separated at the outset.
- PDF p3, math: Direct and indirect effects receive an economic interpretation immediately after the display.
- PDF p5, literature: Connections to prior work are organized around representation and adjustment margins.
- PDF p10, interpretation: Differences in point estimates and precision are not treated as the same finding.
- PDF p15, sequence: Empirical disagreement motivates the model's next task.
- PDF p17, measurement: An observed average earnings measure is separated from the model wage rate.

## R08

[Dynamic Spatial General Equilibrium](https://stephenredding.github.io/redpublish.htm)

Benny Kleinman; Ernest Liu; Stephen Redding. Published Econometrica article, March 2023.

Selected passages: PDF pp1, 2, 3, 4, 5, 10, 20, 37.

**Argument map:** Adjustment question -> migration and investment obstacle -> agent distinction -> equilibrium -> transition matrices -> empirical application.

- PDF p1, obstacle: The introduction gives a concrete reason dynamic joint decisions are hard to model.
- PDF p2, assumption: The worker-landlord distinction is introduced for its computational role.
- PDF p4, literature: Dynamic approaches are compared by the intertemporal decisions they retain.
- PDF p10, notation: A change in subscript order is explained rather than left implicit.
- PDF p20, math: An eigenvector decomposition is followed by its adjustment-speed interpretation.
- PDF p37, conclusion: The conclusion returns to the original adjustment question and analytical contribution.

## R10

[Quantitative Urban Economics](https://stephenredding.github.io/redpublish.htm)

Stephen Redding. Published handbook chapter, chapter pagination starts at 74.

Selected passages: PDF pp2, 3, 4, 6, 15, 22, 42, 61.

**Argument map:** Within-city patterns -> choices and frictions -> baseline model -> inversion -> validation -> useful extensions.

- PDF p3, scope: Geographic scale changes which interactions matter most.
- PDF p6, validation: Matching levels is distinguished from evaluating responses to a historical shock.
- PDF p15, math: Choice probabilities and wages depend on the specified interpretation of heterogeneous draws.
- PDF p22, sequence: Inversion proceeds in numbered economic tasks with normalization stated.
- PDF p42, literature: Consumption travel is introduced because commuting alone omits an important motive.
- PDF p61, conclusion: The conclusion links substantive urban mechanisms to what the models can explain.
