# Expanded Corpus Vocabulary

For work invoking the expanded skill, use the 31-paper inventory in this edition.
The original 23-paper inventory remains frozen and can still be selected explicitly.
The expansion changes attestation coverage, not the scientific conditions governing
a claim or the requirement to justify an essential exception.

Every recognized form has source-paper and PDF-page evidence. Main-text ranges
are approximate; bibliographies, notation, names, and extraction problems can still
contribute forms. Newly attested words are not all useful economic prose. Inspect
context before using a rare, other-page, or technical expression. Neither a larger
inventory nor an example sentence licenses a new economic concept.

No stemming, free inflection, synonym allowance, or automatic compound approval
has been added. The exception register remains the original empty register unless
an author supplies a separate, narrowly approved policy. The vocabulary checker
does not expand TeX inputs and does not verify equations or argument validity.

Use plain words where they carry the exact meaning. If a necessary method name,
provider name, or distinction is missing, retain its meaning and request a specific
exception rather than hiding it in math or changing the scientific statement.

## Version and Preservation

`data/BASELINE_FREEZE.json` binds the original sources, extracts, data, analysis,
and vocabulary. `vocabulary/BUILD_RECEIPT.json` binds the new sources, page extracts,
combined database, counts, and outputs. The added forms are listed separately in
`vocabulary/new_attestations.csv`; no old inventory is silently enlarged.

The original selected vocabulary and usage dictionary remain useful. The new
usage supplement explains additional distinctions but is not itself attestation
evidence. Writing tests report lexical checks and substantive review separately.
