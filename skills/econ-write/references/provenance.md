# Provenance and Source Use

## Upstream package

This skill incorporates and reorganizes material from Lu Han's
[`econ-writing-skill`](https://github.com/hanlulong/econ-writing-skill), pinned for this
consolidation at commit `f2bf7a22c5e3b37921a5e6c73bd1fb380a5e00e8`. The upstream package is
MIT licensed; see `../LICENSE.econ-writing-skill`.

The local version changes the upstream operating contract in three important ways:

1. author-side review remains separate from independent `referee-report` judgments;
2. missing estimates, citations, datasets, institutional facts, and policy details are never
   replaced with invented illustrative values; and
3. numerical length rules, field conventions, and journal policies are defaults that require
   current primary-source verification when they matter.

## Main source families

The imported guidance synthesizes economics-writing advice associated with John Cochrane,
Deirdre McCloskey, Jesse Shapiro, Keith Head, Marc Bellemare, Claudia Goldin, Lawrence Katz,
Edward Glaeser, Hal Varian, Michael Kremer, Plamen Nikolov, Jonathan Schwabish, and others.
Use these attributions to locate the original source; do not cite the skill as evidence for an
academic claim.

The upstream ranked inventory is a discovery aid, not an independently verified bibliography.
Before quoting, citing, or relying on a claimed journal rule, open the original guide or current
journal documentation and verify the relevant passage.

## Maintenance rule

Do not overwrite the local skill with an upstream installer. Compare a pinned upstream revision
against the local references, import useful changes selectively, preserve the local safety and
routing boundaries, and update the pinned commit recorded above.
