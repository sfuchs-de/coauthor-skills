# Sources

- Jonathan Dingel, [Project template](https://github.com/jdingel/projecttemplate): task-based organization, automated builds, Git history, collaborative assignments and review, and a project logbook.
- Jonathan Dingel, [Advice for PhD students and recommended resources](http://www.jdingel.com/teaching/advice.html): plain-text tools, version control, build automation, and principled data processing.
- Matthew Gentzkow and Jesse Shapiro, [Code and Data for the Social Sciences](https://web.stanford.edu/~gentzkow/research/CodeAndData.pdf).
- Kieran Healy, [The Plain Person's Guide to Plain Text Social Science](https://plain-text.co/).

Dingel's project template evaluates research infrastructure by replicability, portability, modularity, dependency management, and recoverable history. This skill operationalizes those tests without copying the template.
