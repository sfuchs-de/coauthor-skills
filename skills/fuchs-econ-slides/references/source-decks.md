# Source Deck Provenance

The bundled synthetic template distills Simon Fuchs's NBER/Cowles presentation conventions.
Original decks, local paths and working-paper findings are intentionally not distributed.
Inspect a collaborator-provided reference only when it is available and authorized, and when the
synthetic template does not resolve a design choice.

The mature style uses progress strips, a semantic palette, experiment/results hierarchy, figure
provenance, section dividers and linked technical backup. The earlier style has smaller text and
less developed navigation; do not treat an older precedent as automatically authoritative.

When sources disagree, prefer the current manuscript or verified model/data result for substance,
the project's chosen template for visual convention, and an authorized stepped version for reveal
logic. Historical references must not resurrect obsolete findings or override current evidence.
