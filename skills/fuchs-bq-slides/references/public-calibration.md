# Public visual calibration

Use the synthetic `assets/deck/` example to calibrate the white background, blue hierarchy,
generous spacing, incremental argument, claim-led title, persistent notation and linked backup.
Render it locally when a visual comparison would help. The design-system, argument-and-length,
and evidence-and-QA references preserve the applicable protocols.

The personal reference contact sheet and its manuscript-specific snapshot are intentionally not
included. An authorized reference supplied by a collaborator can be inspected for visual choices,
but its claims, numerical results, coauthors and private assets must not migrate into a new deck.
