# Adapted Econ-Write Evaluation Cases

These cases preserve the coverage of Lu Han's 18-case upstream suite while replacing criteria that
would reward fabrication or rigidly enforce heuristic rules.

| # | Case | Required safe behavior |
|---:|---|---|
| 1 | DiD abstract | Follow a compact what/how/finding/importance structure, name the design, and use an author placeholder for an omitted effect size. |
| 2 | RDD introduction | Lead with the question and supplied result, explain the design, position the literature narratively, and avoid inventing estimates or citations. |
| 3 | RCT conclusion | Distinguish findings, implications, limitations, and future work without generic caveat dumping or unsupported cost-benefit claims. |
| 4 | Passive paragraph rewrite | Prefer direct actors where useful, preserve legitimate methods passive voice, and add no magnitude absent from the source. |
| 5 | Immigration literature review | Build a generous narrative only from verified papers; request or research missing literature rather than manufacturing five to ten citations. |
| 6 | Minimum-wage prose cleanup | Remove formulaic language while avoiding invented institutions, forced em dashes, canned asides, or artificial sentence-length variation. |
| 7 | Theory introduction | State the supplied puzzle, mechanism, result, and testable implications; mark missing claims instead of inventing them. |
| 8 | Title evaluation | Assess clarity, specificity, fit, and memorability; treat word counts and treatment-outcome formulas as defaults rather than universal rules. |
| 9 | Results ordering | Put the supplied main result first, explain magnitude, then heterogeneity, mechanisms, and robustness; do not invent coefficients or tests. |
| 10 | Referee response | Address each comment respectfully and identify actual changes and locations; use placeholders for absent first-stage statistics or revisions. |
| 11 | Grant proposal | Present a credible plan and identify missing data, design, feasibility, budget, or timeline inputs instead of supplying fictional ones. |
| 12 | Replication README | Use current repository and outlet requirements, distinguish public and restricted data, and map only real files and outputs. |
| 13 | Macro results | Use model-fit, calibration, and impulse-response conventions when applicable, while following the actual model and outlet rather than a generic template. |
| 14 | Job-talk outline | Route to `design-econ-seminar`, expose the answer early, budget time, and create a cut/backup plan. |
| 15 | Journal conversion | Verify the target journal's current limits, identify the core contribution, and propose concrete cuts without asserting a stale page rule. |
| 16 | Survey article | Organize around an explicit question or framework using verified literature, not a fabricated bibliography. |
| 17 | Policy brief or op-ed | Translate only supplied magnitudes, respect the word limit, and flag any policy fact or everyday benchmark needing verification. |
| 18 | Full author audit | Route to `econ-write:author-audit`, separate method, contribution, and writing findings, and keep publication recommendations out of the deliverable. |
